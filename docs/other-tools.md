# ほかのツールとの併用

## テクスチャを加工するツール

- Tocoloはアップロード時の処理を、ほかのテクスチャ加工ツールより先に行います。ほかのツールの結果の上に色を載せたいときは、先にそのツールでエクスポートしてから、Tocoloで色を変えてください。
- アップロード時にテクスチャへ書き込むツールがあると、プレビューでは、そのツールの効果がTocoloの色変えの上に表示されないことがあります。アップロード後は上に掛かります。該当するツールがあるときは、編集を選んだときにパネルへ案内が出ます。

## キメラヘアマスター

- キメラヘアマスター（1.6.5以降）の対象の髪で、メッシュ統合がOFFのものには、プレビューでもアップロードでも、キメラヘアマスターの色合わせの上に色を重ねます（範囲は元のテクスチャで選びます）。
- メッシュ統合がONの髪には重ねられません。統合をOFFにするか、エクスポートしてから使ってください。
- どちらもパネルに案内が出ます。
- キメラヘアマスターの髪には、Tocoloの[色合わせ](features/color-match.md)は使えません。

## マテリアルを差し替えるツール・アニメーション

アニメーションや、ほかのツールのマテリアル差し替え機能で、あとから割り当てられるマテリアルには反映されません（Rendererに最初から付いているマテリアルだけを見ます）。

## 圧縮系のツール

NDMFの最適化の段階で動く圧縮系のツールとは、一緒に使えます。Tocoloの結果が、そのまま圧縮の対象になります。

## Quest用にマテリアルを変換するツール

元のテクスチャから新しいマテリアルを作るため、色変えが載らないことがあります。先にTocolo Proの［メインに焼き込み］で書き出してから変換してください（[書き出し](features/upload-export.md#書き出し)）。
