# 更新履歴

体験版とTocolo Proは同じ版で出しています。更新はVCC・ALCOMで、両方をそろえて行ってください。

## 1.0.0（2026-11-28）

- 色変えの設定を、1つのファイル（プロファイル）にして別のアバター・別のプロジェクトに移せるようにしました（[プロファイル](features/profile.md)）。体験版でも使えます。
  - Inspectorの［プロファイル作成］で、入れる編集を選んでファイルにします。［画像を入れる］の画像・なぞって選んだ範囲・色合わせの明るさの山の形も入ります。
  - ファイルを移す先のSceneのパネルにドロップすると読み込みます。移す先に編集があれば［上書き］［足す］［キャンセル］から選びます。Ctrl＋Z 1回で戻せます。
  - 移す先では、同じメッシュの同じ面を探して付けます。テクスチャは移す先のマテリアルから取り直すので、色違いの衣装にも入ります。
  - 移せなかった編集は、読み込みのあとに理由と一緒に一覧で出ます。
  - ［画像を入れる］にアバターのテクスチャを使った編集は、プロファイル作成のウィンドウで警告が出ます。
- 利用規約に、プロファイルの扱いを足しました（[利用規約](terms.md)）。
- Inspectorの編集一覧を、見出しの矢印で畳めるようにしました。

## 0.8.0（2026-11-28）

- グラデーションに［箱｜毛先グラデ］の切り替えを追加しました。毛先グラデでは、房ごとに毛先が色1、毛先から指定の長さだけ離れた所が色2になります。ツインテールのように、毛先がいろいろな向きを向く髪でも、毛先だけに色を入れられます。
- 毛先グラデの長さは、cmか%で指定します。長さの行の画鋲のボタンを押してSceneビューの髪をクリックすると、その場所まで毛先の色が入る長さになります。
- グラデーションの［色1｜色2］の横に［⇔］を追加しました。色・陰影の暗さ・ガンマ・不透明度と途中の色を、まとめて上下逆にできます。
- Ctrl＋Shift＋ドラッグで、枠の中のパーツをまとめて外せるようにしました。
- ［＋残りのパーツも選ぶ］の右に［＋メッシュ内だけ］を追加しました。同じ画像を別のメッシュでも使っているとき、選んでいるメッシュの中だけを足せます。
- 更新のお知らせを追加しました。初めて使うときに使うかどうかを聞き、使うを選ぶまでは通信しません（[通信の詳しい内容](features/update-notice.md#通信の詳しい内容)）。
- スポイトなどの道具を持ったあと、Sceneビューをクリックするまで、Escキーでやめられなかったのを直しました。
- 境界（Bounds）が潰れている髪で、見る向きによってクリックできなかったのを直しました。

## 0.7.1（2026-11-22）

- グラデーションに途中の色を足せるようにしました（6色まで）。見本の下の▲の無い所を押すと足せます。途中の▲は左右にドラッグして動かし、選んでいる間は［削除］で消せます。
- 途中の色が持つのは色だけです。陰影の暗さ・ガンマ・不透明度は、色1と色2から決まります。

## 0.7.0（2026-11-21）

- 色のブロックに［色を指定｜色合わせ］の切り替えを追加しました。お手本の髪の、暗い所から明るい所までの色味を写せます。お手本は、Sceneビューでクリックするか、Rendererをドラッグ＆ドロップして選びます。
- 明るさの山をつかんで、全体の明るさ・陰影の暗さ・ハイライトの伸びを変えられます。
- 「なぞって調整」を「範囲をなぞって選ぶ」に改め、範囲の「▸ 設定」の中に移しました。
- ［テクスチャの残りを選択］を［＋残りのパーツも選ぶ］に改めました。

## 0.6.0（2026-10-25）

- パーツモードに「なぞって調整」を追加しました。UVが分かれていない髪でも、メッシュカラーやインナーカラーの範囲を、Sceneビューでなぞって足したり消したりできます。
- 数秒で消える案内が消える瞬間に、Consoleにエラーが出ることがあったのを直しました。

0.6.0より前の変更は省略しています。
