# 用語と操作

## 用語

| 言葉 | 意味 |
|---|---|
| 編集 | 1回のクリックで作られる「範囲＋色＋設定」のまとまりです。Inspectorの編集一覧に並びます |
| パーツ | UVでつながったひとかたまり（UVアイランド）です |
| 連結 | マテリアルをまたいで足したときに作られる、テクスチャごとの編集の組です。色や設定を共有します |
| 色1／色2 | 目標の色です。グラデーションでは、箱の下端（毛先グラデでは毛先）が色1、上端が色2です |
| 元の色 | クリックした場所のテクスチャの色です |
| お手本 | 色合わせで色味を合わせる相手の髪です |
| 選択範囲 | 編集の範囲の縞模様です。小窓「表示切替」で出し入れします |
| 箱 | Sceneビューに出る箱です。箱の中（水色）・グラデーション・画像（青緑。シールなら枠）があります。小窓「表示切替」で出し入れします |
| シール | 画像の初期の貼り方です。面に沿って貼ります |
| 焼き込み | 色変えや画像を、メインテクスチャに描き込むことです。なめらかに貼る画像は、焼き込まずに重ねて表示します |
| プロファイル | 編集を別のアバター・別のプロジェクトに移すためのファイルです（[プロファイル](features/profile.md)） |

## 操作

| 操作 | 動き |
|---|---|
| クリック | 範囲を選びます（新しい編集）。編集済みの範囲なら、その編集を選び直します |
| Shift＋クリック | いつも新しい編集を作ります |
| Ctrl＋クリック | 今の編集にパーツを足す・外します |
| Ctrl＋ドラッグ | 枠の中のパーツをまとめて足します（「パーツ」のとき） |
| Ctrl＋Shift＋ドラッグ | 枠の中のパーツをまとめて外します |
| 画像をドラッグ | 面に沿って動かします |
| なぞる | 範囲の「▸ 設定」の［足す］か［消す］を押してからドラッグします。Ctrlで足す・消すを入れ替えます |
| Esc | スポイト・お手本選び・毛先グラデの長さ選び・なぞるブラシ・画像のドラッグをやめます。何もしていなければScene編集を終了します |
| Ctrl+Z | 元に戻します（Undo） |
| 右端のつまみ | パネルを拡大縮小します |
| Sceneのパネルにプロファイルをドロップ | プロファイルを読み込みます |
