# Tocolo（トコロ）

Tocoloは、Sceneビューでアバターをクリックした場所の色を、陰影を保ったまま変えるUnityのツールです。クリックした所に使われているメインテクスチャの一部の色を変えます。元の陰影（明暗の分布）はそのまま残るので、塗り直したような不自然さが出ません。

![アバターの左半分が変更前、右半分がTocoloで髪の色を変えた後（プレビュー表示）。陰影はそのまま残る](/img/tocolo/fig1.png)

シーンにある元のテクスチャ・マテリアルは書き換えません（NDMFによる非破壊）。結果はSceneビューのプレビューで確かめられ、Tocolo Proを入れていればアップロード時に自動で反映されます。

## 体験版とTocolo Proの違い

| | 体験版（無料） | Tocolo Pro |
|---|---|---|
| Sceneでクリックして範囲を選ぶ・色を変える | ○ | ○ |
| グラデーション・色合わせ・除外リスト・複数選択 | ○ | ○ |
| 画像を入れる（Sceneで貼って確かめる） | ○ | ○ |
| プロファイル（別のアバター・プロジェクトへ移す） | ○ | ○ |
| NDMFプレビュー（Sceneに結果を表示） | ○ | ○ |
| アップロード時に反映（色変え・画像とも） | × | ○ |
| 書き出し（メイン／lilToon 2nd／マスク） | × | ○ |

体験版では、色を変えた状態でアップロードしても、元の色のままアップロードされます。アップロード自体は失敗せず、NDMFの報告ウィンドウに案内が出ます。Tocolo Proを追加すると、体験版で作った編集はそのまま引き継がれます。

## 必要なもの

- Unity 2022.3
- VRChat SDK（Avatars）3.7.0以降
- NDMF 1.14.0以降（Tocoloを入れると一緒に入ります）

## インストール

1. ダウンロードしたファイルに入っている「…をVCC・ALCOMに追加」を開きます。VCC（またはALCOM）が開き、リポジトリの追加画面になるので、［Add］（追加）を押します。
2. VCC（またはALCOM）で、使いたいアバターのプロジェクトを開き、「Tocolo」を追加します。

Tocolo Proを購入した場合は、購入者向けの「…をVCC・ALCOMに追加」を使ってください。「Tocolo」と「Tocolo Pro」の両方が同じ一覧に出るので、両方を追加します。

:::tip[VCC・ALCOMが開かないとき]
同梱の案内に書かれたリンクをコピーして、VCC（またはALCOM）の「Add Repository」に貼り付けてください。
:::

## 更新と削除

- **更新**：VCC（またはALCOM）のプロジェクトの画面で、Tocoloのバージョンを新しいものに変えます。変わった内容は[更新履歴](/changelog)にまとめています。
- **体験版とTocolo Proは必ず同じ版にそろえてください。** Tocolo Proは体験版の内部の仕組みを使っているので、片方だけ新しいとコンパイルエラーになることがあります。
- **アバターから外す**：アバターのルートにある「Tocolo」コンポーネントを、Inspectorの右クリックメニューの「Remove Component」で外します。編集はコンポーネントと一緒に消え、元のテクスチャ・マテリアルはそのまま残ります（外すだけで元の見た目に戻ります）。
- **プロジェクトから削除**：VCC（またはALCOM）のプロジェクトの画面で、Tocolo（とTocolo Pro）を削除します。

最新版が出たときは、Scene編集中にお知らせが出ます（使うかどうかを最初に聞きます）。くわしくは[更新のお知らせ](features/update-notice.md)を見てください。
