# 更新のお知らせ

最新版の更新があると、Scene編集中に、「Tocolo: 操作」の小窓の上へ「最新版〇〇があります」と出ます。困ったときは、まず最新版に更新してみてください。

最初にScene編集を始めたとき、お知らせを使うかを聞かれます。［お知らせ機能を使う］を押すと使えます。［使わない］を押すと、通信もお知らせもしません。どちらかを押すまでは通信しません。

- ［更新履歴を見る］で、変わった内容を確認できます。
- ［この版はスキップ］を押すと、その版のお知らせは出なくなります（さらに新しい更新が出たら、また出ます）。
- ［閉じる］を押すと、次にScene編集を始めるまで出なくなります。
- あとから切り替えるときは、メニューの「Tools > Tocolo > 更新を確認する」のチェックを付けたり外したりします。

Tocolo Proを入れている場合も、体験版と同じ版で出しているので、お知らせは1つです（両方を更新してください）。

お知らせするだけで、勝手に更新はしません。アバターやアップロードにも何も入りません。

## 通信の詳しい内容

最新版があるかを確かめるために、インターネットにつなぎます。何を送り、何を受け取り、何を保存するかは次のとおりです。

**いつ**

- Unityの起動時など（スクリプトを読み込み直したとき）に、前回の確認から24時間たっていれば、1回だけ確かめます。
- ［お知らせ機能を使う］を押した直後と、メニューでチェックを付けた直後にも、1回確かめます。
- ［お知らせ機能を使う］を押す前と、「更新を確認する」のチェックを外しているときは、通信しません。

**どこへ**

- GitHub Pages（GitHub社のサービス）に置いてある、Tocoloのバージョン一覧のファイル（体験版の`index.json`）です。
- VCC・ALCOMに追加した体験版のURLと同じ、誰でも見られる公開ファイルです。Tocolo Proの購入者向けの一覧は読みません。

**送るもの**

- `index.json`を取得するための、ふつうのリクエスト（HTTPSのGET）だけです。Tocoloが付け足す情報はありません。
- 通信の仕組み上、IPアドレスと、Unityが自動で付ける識別文字列（User-Agent。Unityのバージョンなど）がGitHub社に届きます。作者がこれらを見られる仕組みはありません。
- アバター・プロジェクト・PCの情報や、お使いのTocoloのバージョンは送りません。

**受け取るもの**

- `index.json`の中身です（各バージョンの番号・対応するUnityのバージョン・ダウンロード先など）。
- 使うのは、バージョン番号と、対応するUnityのバージョンだけです。最新版を探すとき、プレリリース版と、お使いのUnityで使えない版は入れません。
- ファイルの中の文章やURLは、表示も開きもしません（ボタンで開くのは、この説明書のページだけです）。

**保存するもの**

- このPCのUnityの設定（EditorPrefs）に、最新のバージョン番号・最後に確かめた日時・スキップしたバージョン番号・「更新を確認する」のON/OFF・お知らせの小窓の位置と大きさを保存します。
- プロジェクトやアバターには保存しません。

**しないこと**

- ダウンロードや更新は、自動ではしません（更新はVCC・ALCOMで行ってください）。
- アップロードするアバターには何も入りません（Unityのエディタの中だけで動きます）。
- インターネットにつながらないときや、確かめるのに失敗したときは、何も表示せず、そのまま使えます。
