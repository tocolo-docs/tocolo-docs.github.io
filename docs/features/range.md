# 範囲の選び方

クリックしたときに、どこまでを色変えの対象にするかを決めます。パネルの上の青い「範囲」のブロックで設定します。

## 影響範囲

| モード | 選ばれる範囲 | 向いている場面 |
|---|---|---|
| パーツ | クリックしたパーツ（UVのひとかたまり）をまるごと。なぞって面ごとに足す・消すこともできます（[範囲をなぞって選ぶ](paint-select.md)） | 袖・襟・リボンなど、パーツ単位で変えたいとき |
| 箱の中 | パーツやUVの切れ目に関係なく、Sceneに出る箱の内側（[箱の中](box-range.md)） | 髪のツートン、袖の先だけ、腰から下だけなど、場所で区切りたいとき |
| 同じ色 | クリックした場所とほぼ同じ色で、途切れずにつながる部分 | 模様や線、単色の帯 |
| 似た色 | 近い色を広めに | グラデーションや影のある部分 |

モードを切り替えると、選んでいる編集にもすぐ反映されます。

### 残りのパーツも選ぶ

影響範囲が「パーツ」のとき、モードのボタンの下に［＋残りのパーツも選ぶ］が出ます。押すと、そのテクスチャのまだ選んでいないパーツを全部足します（除外リストのRendererは除きます。「各点の色を揃える」はOFFになります）。要らないパーツは、Ctrl＋クリックで外せます。

同じ画像を使う別のメッシュ（前髪と後ろ髪など）を除きたいときは、右の［＋メッシュ内だけ］を押します。選んでいるパーツと同じメッシュの中だけを足します。

## 設定項目

### パネルに出ている項目（同じ色・似た色）

| 項目 | 説明 |
|---|---|
| しきい値 | どれくらい近い色まで選ぶかです。大きいほど広く選びます |
| ぼかし | 選んだ範囲の境目をなめらかにする幅です |
| 範囲 | 色を探す場所です。「つながった範囲」「パーツの中」「テクスチャ全体」「アバター全体(重いかも)」から選びます |

### 「▸ 設定」の中

| 項目 | 説明 |
|---|---|
| マテリアルをまたいで選ぶ | 別のマテリアルのパーツも同じ編集に足せるようにします（[下](#複数のパーツをまとめて変える)） |
| 隠れている範囲も選ぶ | ドラッグ選択で、奥に隠れたパーツも選びます（[下](#複数のパーツをまとめて変える)） |
| 範囲をなぞって選ぶ | 「パーツ」のときに出ます（[範囲をなぞって選ぶ](paint-select.md)） |
| ゴマ塩除去 | 「同じ色」「似た色」のときに出ます。塗りに混じる細かい点を取り除きます |
| はみ出し幅 | パーツのまわりの、UVで使われていない部分まで色を広げる幅（ピクセル）です。つなぎ目に元の色の線が見えるときは上げてください。マイナスにすると縁を削ります |

## 複数のパーツをまとめて変える

| 操作 | 説明 |
|---|---|
| Ctrl＋クリック | 同じ編集にパーツ（点）を足す・外す。離れたパーツを1つの色でそろえたいときに使います |
| Ctrl＋ドラッグ | 枠の中に見えているパーツをまとめて足します（「パーツ」のときだけ）。枠を描き始めた場所のパーツが主になります |
| Ctrl＋Shift＋ドラッグ | 枠の中のパーツをまとめて外します（枠が赤くなります）。全部外すと、その編集ごと消えます |

![Ctrl＋ドラッグの枠で選んだところ。入ったパーツが縞模様で足される](/img/tocolo/fig5.png)

関係する設定が3つあります。

- **隠れている範囲も選ぶ**（範囲の「▸ 設定」）：ONにすると、ドラッグ選択で、ほかのメッシュの奥に隠れたパーツも、枠に入っていれば選びます。Ctrl＋クリックには効きません。
- **マテリアルをまたいで選ぶ**（範囲の「▸ 設定」）：ONにすると、別のマテリアル（別のテクスチャ）のパーツも同じ編集に足せます。テクスチャごとの編集が自動で連結され、色や設定はまとめて効きます。
- **各点の色を揃える**（色の「▸ 設定」。点が複数のときに出ます）：ONでは点ごとに目標の色にそろえます。OFFでは、点どうしの明るさの差を保ちます。

## 除外リスト

ドラッグ選択などで巻き込みたくないパーツは、そのRendererを除外リストに登録します。登録したRendererは、Sceneでクリックしてもドラッグ選択で囲んでも選ばれません。

見た目には影響しません。共有テクスチャに掛かった編集はそのまま映り、アップロードや書き出しも通常どおりです（「箱の中」だけは例外で、除外したRendererは箱に入っていても色が変わりません）。

1. パネルの上の［除外リスト］（［編集一覧］の右）を押すと、パネルの隣に小窓が開きます。
2. HierarchyのGameObjectを、ドロップ枠にドロップします。そのGameObjectのRenderer（無ければ子のRenderer全部）が登録されます。
3. 一覧の［×］で1件ずつ、［すべて外す］でまとめて外せます。

![除外リストの小窓。ドロップ枠にGameObjectを落とすとRenderer単位で並ぶ。パネルのボタンには件数が出る](/img/tocolo/fig8.png)

Inspectorの「選択しないRenderer」でも、同じ一覧を編集できます。
