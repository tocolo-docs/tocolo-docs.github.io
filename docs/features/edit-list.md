# 編集一覧とInspector

1回のクリックで作られる「範囲＋色＋設定」のまとまりを、編集と呼びます。作った編集は、Sceneのパネルの小窓「編集一覧」と、Inspectorの「編集一覧」で見られます。

## Sceneのパネルの小窓「編集一覧」

パネルの上の［編集一覧］（数字は色を決めた編集の数）を押すと、パネルの横に、対象アバターの編集が並びます。除外リストと同じ場所に出るので、片方を開くともう片方は閉じます。

![小窓「編集一覧」。行を押すとその編集を選び、左のチェックで有効／無効を切り替える](/img/tocolo/fig14.png)

- 行を押すと、その編集を選びます（Sceneビューで選び直すのと同じです）。今選んでいる行は青くなります。
- 左のチェックで、有効／無効を切り替えます。
- 名前・色の見本・種類（パーツ・箱・色・画像）と、反映されない編集の警告の印が出ます。
- 名前の変更と並べ替えは、Inspectorの編集一覧で行います。編集を消すときは、選んでからパネルの［この編集を削除］を押します。
- 編集が多いときは、Sceneビューの高さでスクロールになります。

## Inspector

アバターのルートの「Tocolo」コンポーネントを選ぶと、Inspectorに次の項目が出ます。

![InspectorのTocoloコンポーネント。上から［Sceneで色を変える］、編集一覧（見出しの矢印で畳める）、プロファイル、書き出し、設定の項目](/img/tocolo/fig2.png)

| 項目 | 説明 |
|---|---|
| ［Sceneで色を変える］ | Scene編集を始めます（Play中・Prefabの編集モード中は押せません）。Scene編集中は［Scene編集を終了］になります |
| 編集一覧 | 作った編集の有効／無効、名前、並べ替え、削除、［Sceneで選ぶ］。見出しを押すと畳めます（開け閉めはPCごとに覚えます） |
| ［見つからない編集を削除］ | クリックしたパーツが見つからない編集を、まとめて消します（あるときだけ押せます） |
| ［すべて削除］ | 編集を全部消します |
| プロファイル | ［プロファイル作成］で、編集を別のアバター・別のプロジェクトに移すファイルを作ります（[プロファイル](profile.md)） |
| 書き出し（Tocolo Pro） | 色を変えたテクスチャをファイルにします（[書き出し](upload-export.md#書き出し)） |
| プレビューの解像度 | Sceneビューのプレビューで使う解像度の上限です。小さいほど軽く動きます。アップロードと書き出しは元の解像度で行います |
| プレビューを表示 | OFFにすると、Sceneビューの表示が元に戻ります（編集は残ります） |
| ビルド時に適用（Tocolo Pro） | アップロード時に色変えを反映するかです（[アップロード時に反映](upload-export.md#アップロード時に反映)） |
| 生成テクスチャの圧縮（PC）・（Quest）（Tocolo Pro） | 生成するテクスチャの圧縮形式です（[生成テクスチャの圧縮](upload-export.md#生成テクスチャの圧縮)） |
| 選択しないRenderer | Sceneビューで選ばれなくするRendererの一覧です。パネルの［除外リスト］と同じ一覧です（[除外リスト](range.md#除外リスト)） |

### 警告の印

反映されない編集には、編集一覧に警告の印が出ます。印にマウスを乗せると理由が出ます。

| 理由 | 直し方 |
|---|---|
| クリックしたパーツ（Renderer）が見つからない | パーツが削除された可能性があります。［見つからない編集を削除］でまとめて消せます |
| テクスチャを、アバター内のどのマテリアルも使っていない | マテリアルを差し替えた場合は、元のテクスチャを使うマテリアルに戻すと再び効きます |
| テクスチャ・画像が見つからない | ファイルが削除された可能性があります |
