# 色合わせ

色を1つ選ぶ代わりに、別の髪（お手本）の色味に合わせます。お手本の暗い所から明るい所までの色と、明るさの散らばり方を写すので、ショップの違う髪どうしでも、陰影の付き方ごと色味をそろえられます。

**場所**：色のブロックの一番上の［色合わせ］

| 色合わせの前 | 色合わせの後 |
|---|---|
| ![色合わせの前。左がお手本の髪、右が色を合わせたい髪](/img/tocolo/fig18a.png) | ![色合わせの後。右の髪がお手本の色味にそろう（少し調整）](/img/tocolo/fig18b.png) |

## 使い方

1. 変えたい髪をクリックして、範囲を選びます。影響範囲はふだんどおり（パーツ・箱の中・同じ色・似た色）です。
2. 色のブロックの一番上の［色合わせ］を押します。Sceneビューでお手本を選ぶ状態になり、パネルに案内が出ます。
3. Sceneビューで、お手本にする髪をクリックします。その場で色を測り、すぐに色が変わります。
4. 必要なら、[明るさの山](#明るさの山)やスライダーで、お手本からずらします。

アバターの外にある髪（お手本用に置いた別の髪など）は、パネルの「お手本」の欄に、Hierarchyからドラッグ＆ドロップします。

![色合わせの欄。上から［色を指定｜色合わせ］、お手本の行、見本の行、明るさの山、スライダー](/img/tocolo/fig19.png)

## 設定項目

### お手本の行

| 項目 | 説明 |
|---|---|
| 左のボタン | 押すと、Sceneビューでお手本を選ぶ状態になります。もう一度押すか、Escキーでやめます |
| 欄 | お手本のRendererです。空にするとお手本を外し、この編集は色を変えなくなります |
| マテリアル | お手本にマテリアルが複数あるときに出ます。どのマテリアルの色に合わせるかを選びます |

### 見本の行

左の「お手本の色」は、お手本の代表の色です。右の「合わせた色」は、合わせた結果の代表の色です。「お手本の色」か［リセット］を押すと、ずらしとガンマをお手本どおりに戻します（不透明度はそのままです）。

### 明るさの山

横が明るさ（左が暗い）、高さがその明るさの部分の多さ、色が合わせた後の色です。薄い灰色の山は、ずらす前（お手本どおり）の形です。山・線・下の▲は、つかんで動かせます。

| つかむ所 | 変わるもの |
|---|---|
| 山の本体・中の▲ | 左右にドラッグすると、全体の明るさが変わります |
| 左の線・左の▲ | 陰影の暗さが変わります |
| 右の線・右の▲ | ハイライトの伸びが変わります |

▲が重なったときは、中の▲の少し左を押すと影、少し右を押すとハイライトをつかめます。

### スライダー

| 項目 | 説明 |
|---|---|
| 明るさ | 全体を明るく・暗くずらします（山の本体と同じです） |
| 色相・彩度 | 色味を回す・鮮やかさを足し引きします |
| 陰影の暗さ | 暗い所の暗さです（山の左の線と同じです） |
| ハイライトの伸び | 明るい所の伸びです（山の右の線と同じです） |
| ガンマ・不透明度 | ［色を指定］と同じです（[色の調整](color.md#ガンマ)） |

## 範囲と合わせ方

- 色が変わるのは、範囲で選んだ所だけです。合わせ方は、そのテクスチャを使う髪全体の色で決めます。
- ［色を指定］に戻すと、前に指定していた色（無ければ元の色）に戻ります。お手本は覚えているので、［色合わせ］に戻せば同じ色になります。
- 色合わせの間は、グラデーションと画像を入れるのブロックが出ません（その編集では切れます）。設定は残るので、［色を指定］に戻してONにし直せば元どおりです。

## お手本を変えた・消したとき

- お手本の髪を同じアバターのTocoloで色変えしていれば、変えた後の色に合わせます。お手本の色を変えると、こちらも付いてきます（お手本側の色合わせは反映しません）。
- お手本を消したり見つからなくなったりしても、前に測った色で合わせ続けます（パネルに案内が出ます）。アップロードもその色です。

:::info[色合わせが使えないとき]
- 「アバター全体」の編集と、キメラヘアマスターで扱っている髪では使えません。
- お手本と同じテクスチャの髪と、メインテクスチャの無いマテリアルは、お手本にできません。
- お手本の色を読めないとき（メッシュのRead/Writeが無効など）は、有効にしてから、パネルの［もう一度測る］を押してください。
:::
