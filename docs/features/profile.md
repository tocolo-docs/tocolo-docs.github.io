# プロファイル

色変えの設定を1つのファイル（プロファイル）にまとめて、別のアバターや別のプロジェクトに移します。ファイル1つで運べるので、エクスプローラーでコピーして別のプロジェクトに持っていくこともできます。体験版でも使えます。

:::tip[こんなときに使います]
- 同じ髪・衣装を着せた別のアバターにも、同じ色変えを入れたい
- 別のプロジェクトのアバターにも、同じ色変えを入れたい
- 色違いの衣装にも、同じ色変えを入れたい（メッシュが同じなら、テクスチャが違っても入ります）
:::

**場所**：Inspectorの「プロファイル」の［プロファイル作成］

## プロファイルを作る

1. 移す元のアバターのTocoloコンポーネントを選び、Inspectorの［プロファイル作成］を押します。
2. ウィンドウに、色を決めた編集が並びます（最初は全部にチェックが入っています）。入れたくない編集はチェックを外します。［すべて選ぶ］［すべて外す］でまとめて切り替えられます。
3. ［作成…］を押して、保存先を選びます。初期の名前は「アバターの名前.tocolo.json」です。

![［プロファイル作成］のウィンドウ。プロファイルに入れる編集にチェックを入れ、［作成…］を押す](/img/tocolo/profile-1.png)

- 「アバター全体」の編集は「〇〇（アバター全体）」、マテリアルをまたいで連結した編集は「〇〇（N件の連結）」の1行で出ます。
- 色を決めていない仮の編集は出ません。
- ［画像を入れる］の画像、なぞって選んだ範囲、色合わせの明るさの山の形も、ファイルに入ります。
- 髪や衣装のテクスチャ自体は入りません。

## プロファイルを読み込む

1. 移す先のアバターでScene編集を始め、対象のアバターを決めます。
2. ProjectウィンドウかエクスプローラーからプロファイルをドラッグしてSceneのパネルに重ねると、「ここにドロップするとプロファイルを読み込みます」と出ます。そのままドロップします。
3. 移す先に編集がすでにあると、どうするかを聞かれます。
4. 読み込んだ件数と、移せなかった編集が一覧で出ます。

![Sceneのパネル。プロファイルはパネルの上にドロップする](/img/tocolo/profile-2.png)

移す先に編集がすでにあるときは、次のどれかを選びます。

![移す先に編集があるときのダイアログ。［上書き］［足す］［キャンセル］から選ぶ](/img/tocolo/profile-3.png)

| ボタン | 動き |
|---|---|
| ［上書き］ | 読み込む編集と同じテクスチャの編集だけを置き換えます（ほかの編集は残ります） |
| ［足す］ | 今の編集の後ろに足します |
| ［キャンセル］ | 何もしません |

Tocoloがまだ付いていないアバターに読み込むと、Tocoloが付いて読み込まれます。読み込みはUndo（Ctrl+Z）1回で全部戻せます。

別のプロジェクトに持っていくときは、プロファイルのファイルを、移す先のプロジェクトのAssetsの中にコピーしてから、同じようにドロップします。

## 移す先での付き方

移す先では、元のアバターでクリックした所と同じメッシュの同じ面を探して、そこに付けます。

- メッシュは、名前・頂点の数・サブメッシュの数・面の数がすべて同じものを探します。Hierarchyの中の場所が違っていても（空のGameObjectの下に入れた、など）見つかります。
- 同じメッシュが2つ以上あるとき（左右の耳、同じ衣装を2着など）は、Hierarchyの道筋（GameObjectの名前の並び）が近いほうに付けます。決まらないときは付けません。
- テクスチャは、移す先のマテリアルから取り直します。そのため、色違いの衣装にも入ります。
- 選ぶ範囲は、移す先で計算し直します。
- グラデーションの箱・画像の箱・毛先グラデのてっぺんは、髪を基準に置き直すので、素体が違っても髪に付いてきます。
- ［画像を入れる］の画像は、移す先の`Assets/Tocolo/CopiedImages`にできます。読み込みの設定（種類・圧縮・PC/Questごとの設定）も元の画像にそろえます。同じ画像は作り直さずに使い回します（Undoでは消えません）。

## 移せなかった編集

読み込みのあとの一覧に、移せなかった編集と理由が出ます。

| 一覧の見出し | 意味 |
|---|---|
| 移せなかった編集 | 編集ごと移せませんでした。理由は「同じメッシュが見つからない」「同じメッシュが複数あり付け先が決まらない」「メッシュの面の数が違う」「マテリアルにテクスチャが無い」のどれかです |
| 一部の場所（Ctrl＋クリックで足した所）を移せなかった編集 | Ctrl＋クリックで足した所のうち、一部を移せませんでした。移せた所だけで入っています |
| 「アバター全体」の範囲を移す先で選び直した編集 | 移す先のアバターの全テクスチャで選び直しました。髪ごとの調整は元に戻っていることがあります |
| 画像を作れなかった編集 | ［画像を入れる］の画像を作れなかったので、画像なしで入っています |

素体が違うアバターに移したときは、素体の編集が「同じメッシュが見つからない」になるのがふつうです。

## 人に渡すとき

プロファイルは、作った人が自由に使い、共有・配布・販売できます（含まれる画像などの素材の規約に従う範囲で）。人に渡すときは、次の点に気をつけてください。

- ［画像を入れる］で使った画像は、プロファイルにそのまま入ります。購入したアバター・衣装のテクスチャや、配布素材の画像などを入れたプロファイルを、権利者の許可なく配布しないでください。
- ［画像を入れる］に、そのアバターのマテリアルで使っているテクスチャを使った編集は、プロファイル作成のウィンドウで「アバターのテクスチャ」と出て、選ぶと警告が出ます。自分のプロジェクトどうしで移すだけなら問題ありません。
- プロファイルに含まれる画像などの扱いは、それぞれの素材の規約に従ってください。
