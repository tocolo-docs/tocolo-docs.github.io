# やりたいことから探す

## 範囲を決める

| やりたいこと | 使う機能 |
|---|---|
| 袖・襟・リボンなど、パーツ単位で色を変えたい | [範囲の選び方](range.md)の「パーツ」 |
| 模様や線、単色の帯だけ変えたい | [範囲の選び方](range.md)の「同じ色」 |
| グラデーションや影のある部分を広めに変えたい | [範囲の選び方](range.md)の「似た色」 |
| 離れたパーツを1つの色でそろえたい | [複数のパーツをまとめて変える](range.md#複数のパーツをまとめて変える) |
| 別のマテリアルのパーツも同じ色にしたい | [マテリアルをまたいで選ぶ](range.md#複数のパーツをまとめて変える) |
| 巻き込みたくないパーツがある | [除外リスト](range.md#除外リスト) |
| 髪のメッシュカラーやインナーカラーだけを変えたい | [範囲をなぞって選ぶ](paint-select.md) |
| 髪のツートン、袖の先だけ、腰から下だけなど、場所で区切りたい | [箱の中](box-range.md) |

## 色を決める

| やりたいこと | 使う機能 |
|---|---|
| 色を選ぶ・元の色に戻す | [色の調整](color.md) |
| 明るいパステル色にすると暗く見える | [ガンマ](color.md#ガンマ) |
| 陰が灰色っぽい・陰影が弱い | [仕上がりの調整](color.md#仕上がりの調整) |
| 同じ色を指定したのに見え方が違う | [色が狙いとずれるとき](color.md#色が狙いとずれるとき) |
| 別の髪の色味に合わせたい | [色合わせ](color-match.md) |
| 上から下へ色を変えたい | [グラデーション](gradient.md) |
| 毛先だけに色を入れたい | [毛先グラデ](gradient.md#毛先グラデ) |
