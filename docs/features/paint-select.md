# 範囲をなぞって選ぶ

「パーツ」で選んだ範囲を、Sceneビューでなぞって面（三角形）ごとに足したり消したりします。

:::tip[こんなときに使います]
- 髪のメッシュカラー（筋状の色）やインナーカラーだけを変えたい
- 「パーツ」で選ぶと、変えたい所より大きな塊ごと色が変わってしまう（UVがほかの所とつながっている）
:::

**場所**：範囲のブロックの「▸ 設定」の「範囲をなぞって選ぶ」（影響範囲が「パーツ」のとき）

## 使い方

1. 影響範囲を「パーツ」にして、変えたい所を含むパーツをクリックします（パーツがまるごと選ばれます）。Ctrl＋クリックやドラッグ選択で、先にパーツを足しておくこともできます。
2. 範囲のブロックの「▸ 設定」を開き、「範囲をなぞって選ぶ」の［足す］か［消す］を押します。押したボタンが光り、Sceneビューのカーソルにブラシの円が出ます（足すは緑、消すは赤）。
3. Sceneビューでドラッグしてなぞります。ブラシの円に触れた面が、緑（足す）か赤（消す）で重なって見えます。Ctrlを押している間は、足すと消すが入れ替わります。
4. 離すと、範囲と色がまとめて反映されます。1回なぞるごとにUndo（Ctrl+Z）で戻せます。
5. 終わったら、同じボタンをもう一度押すか、Escキーでブラシを置きます（「▸ 設定」を閉じても置きます）。

![パーツを選んでから［足す］でなぞっているところ。ブラシの円に触れた面が緑に重なり、離すと範囲に足される](/img/tocolo/fig16.png)

ブラシを持っている間は、クリックでの選び直し・Shift＋クリック・Ctrl＋クリック・ドラッグ選択は効きません。右下の「Tocolo: 操作」も、なぞりの案内に変わります。

|---|---|
| ![なぞる前。パーツで選ぶと、前髪の大きな塊ごと色が変わる](/img/tocolo/fig17a.png) | ![［消す］でなぞった後。なぞった毛束だけが元の色に戻る](/img/tocolo/fig17b.png) |

## 設定項目

| 項目 | 説明 |
|---|---|
| ［足す］ | 押すとブラシを持ち、なぞった面を範囲に足します。もう一度押すと置きます |
| ［消す］ | なぞった面を範囲から外します |
| ブラシの太さ | ブラシの円の半径（Sceneビューの画面上の大きさ）です。アバターに近づくほど細かくなぞれます |
| ［なぞりを削除］ | なぞって足した・消した所を全部なくし、パーツで選んだ範囲に戻します |
| ブラシのはみ出し | なぞった境目を、＋で外へ（範囲が広がる）、−で内へ（狭まる）ずらします（ピクセル、初期値0）。毛束の色の境目がメッシュの辺とずれているときに使います |

## なぞれる所と、調整の残り方

- ブラシが当たるのは、Sceneビューで見えている面だけです。奥の面をなぞりたいときは、Hierarchyの目のマークで手前の物を隠すか、手前の物を[除外リスト](range.md#除外リスト)に入れてください。
- なぞれるのは、選んでいる編集と同じテクスチャの面だけです（マテリアルをまたいで連結しているなら、そのテクスチャの面も）。
- なぞった調整は、あとでCtrl＋クリックでパーツを足したり外したりしても残ります。影響範囲を「パーツ」以外にすると効かなくなり、「パーツ」に戻すとまた効きます。
- なぞった所はテクスチャの位置で覚えるので、メッシュを入れ直してもUVが同じならずれません。
- 境目は面の辺に沿い、境目の画素は自動でならします。「はみ出し幅」はUVのすき間へだけ広がり、消した面へは広がりません（なぞった境目をずらすのは「ブラシのはみ出し」です）。

:::info[分けられない場合]
変えたい所とほかの所が、テクスチャの同じ場所を使い回している（UVが重なっている）と、なぞって分けても両方一緒に変わります。テクスチャの色変えでは分けられません。

また、色の境目が面の途中に描かれている模様は、面ごとには切れません。「同じ色」「似た色」や[箱の中](box-range.md)を試してください。
:::
