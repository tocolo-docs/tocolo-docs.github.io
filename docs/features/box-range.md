# 箱の中

Sceneビューに出る水色の箱の内側だけを色変えします。パーツやUVの切れ目に関係なく、箱の面のところで色変えが切れます。

:::tip[こんなときに使います]
- 髪をツートンにしたい
- 袖の先だけ、腰から下だけなど、場所で区切って色を変えたい
:::

クリックした場所は、テクスチャと「元の色」を決めるためだけに使います。範囲は箱で決まります。

## 使い方

1. 影響範囲で「箱の中」を選んでから、色を変えたい場所をクリックします（クリックしてから「箱の中」に切り替えてもかまいません）。クリックしたパーツを囲む箱が出ます。
2. 箱の中心のギズモで、移動・回転・全体の拡大縮小をします。移動の矢印と回転の輪は、箱を回してもアバターの向きで出ます。
3. 各面の中央にある橙色の丸をつかむと、その面だけを引いて伸縮できます（マウスが乗ると黄色になります）。

箱を動かしている間は軽い計算で追いかけ、離した瞬間に切り口を細かく描き直します。

## 設定項目

| 項目 | 場所 | 説明 |
|---|---|---|
| 面のぼかし | パネル | 箱の面のところで、色変えをなめらかに切る幅です。0だと面でぱきっと切れます（切り口の階段は、それでも自動でならします） |
| 箱の中の色を揃える | 「▸ 設定」 | ONにすると、箱に入るパーツごとに目標の色にそろえます（「各点の色を揃える」と同じ）。OFF（初期値）では、パーツどうしの明るさの差が残ります。箱を動かしている間は掛からず、離すと掛かります |
| はみ出し幅 | 「▸ 設定」 | ほかのモードと同じです。マイナスで縁を削ります |

## ほかの設定との関係

- **マテリアルをまたいで選ぶ**（「▸ 設定」）：ONなら、箱に触れる別のテクスチャのパーツにも連結して、同じ色になります。OFFにすると、最初のテクスチャだけに戻ります。
- **除外リスト**：「箱の中」では、除外したRendererは箱に入っていても色が変わりません（ほかのモードと違い、見た目にも効きます）。編集中に除外リストを変えると、すぐ反映されます。
- Ctrl＋クリックやドラッグ選択でパーツを足す操作は、「箱の中」では使いません（範囲は箱だけで決まります）。
- [グラデーション](gradient.md)・[画像を入れる](decal.md)と一緒に使えます。初期状態では、あとからONにした方の箱だけが出ます。「箱の中」の箱（水色）も出して動かしたいときは、小窓「表示切替」で［箱の中］を押してください（[小窓「表示切替」](scene-panel.md#小窓表示切替)）。

:::info[切り口の細かさ]
切り口は、プレビューの解像度の画素の刻みです。粗く見えるときは、Inspectorの「プレビューの解像度」を上げてください。アップロードと書き出しは、常に元の解像度で処理します。
:::
