# はじめての色変え

Scene編集を始めて、色を変えたい所をクリックし、色を選ぶだけです。ここでは、いちばん基本の流れを説明します。

## 1. Scene編集を始める

次のどちらかで始めます。

- Sceneビューの左上のツールバーにある、色相環のアイコンを押す
- アバターを選んで、Inspectorの［Sceneで色を変える］を押す（Tocoloがまだ付いていないアバターは、ツールバーのアイコンから始めます）

Sceneビューの左上に「Tocolo」パネル、右下に「Tocolo: 操作」の案内が出ます。

![Scene編集中の画面。左上のツールバーのアイコン（左の丸）で開始し、右の「Tocolo」パネルで範囲と色を調整する。パネルの左に小窓「表示切替」、右下は操作の案内（表示言語の切り替えもここ）。モデル上の小さな丸がクリック位置](/img/tocolo/fig3.png)

## 2. 対象のアバターを決める

シーンにアバターが1体なら、自動で対象になります。複数あるときは、パネルの候補のボタンから選ぶか、Sceneのモデルを直接クリックします。

無効にしたアバターと、Hierarchyの目のマークで隠したアバターは候補に出ません。

## 3. 色を変えたい所をクリックする

クリックした場所を含む範囲が選ばれます。小窓「表示切替」の［選択範囲］がONなら、選ばれた範囲が縞模様で表示されます。マウスを乗せると丸印が出て、どこが当たるかわかります。

![クリック直後。小窓「表示切替」の［選択範囲］がONのとき、選ばれた範囲が縞模様で表示される](/img/tocolo/fig4.png)

最初のクリックで編集を作ったとき、アバターのルートに「Tocolo」コンポーネントが自動で付きます。

どこまでを選ぶかは、パネルの「範囲」のブロックで変えられます。くわしくは[範囲の選び方](../features/range.md)を見てください。

## 4. 色を選ぶ

パネルの「色」のブロックのカラーホイールで色を選ぶと、Sceneのプレビューにすぐ反映されます。カラーコードの入力・最近使った5色・スポイトからも選べます。くわしくは[色の調整](../features/color.md)を見てください。

## 5. 続けて編集する

- 別の場所をクリックすると、新しい編集になります。
- 色を決めた編集の範囲をもう一度クリックするか、［編集一覧］から選ぶと、その編集を選び直せます。
- 同じ場所に重ねて新しい編集を作りたいときは、Shift＋クリックです。

## 6. 終了する

Escキーを押すか、右下の［終了する］を押します。色を決めないまま終了した編集は残りません。

:::tip[元に戻す]
編集の追加・色の変更・箱の操作は、すべてUndo（Ctrl+Z）で戻せます。
:::

## アップロードするとき

Tocolo Proを入れていれば、アップロードするだけで色変えが反映されます。体験版では反映されず、元の色のままアップロードされます。くわしくは[アップロードと書き出し](../features/upload-export.md)を見てください。
